# MECH559 - Engineering Systems Optimization

Coursework for McGill University's MECH559 Engineering Systems Optimization course.

## Setup

The project uses a local Python virtual environment. From the repository root, create it and install the pinned dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Activate the environment when working in the repository:

```powershell
.\.venv\Scripts\Activate.ps1
```
